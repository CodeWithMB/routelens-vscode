# RouteLens

**A VS Code extension for Express.js API discovery, middleware analysis, and security inspection.**

RouteLens helps developers understand their Express.js backend architecture directly inside Visual Studio Code.

## Project Goals

- Automatically discover Express.js API routes.
- Identify HTTP methods, paths, and controllers.
- Analyze middleware chains.
- Recognize JWT authentication and RBAC patterns.
- Highlight potentially unprotected endpoints.
- Navigate directly to route definitions.
- Generate basic API documentation.

## Technology Stack

- TypeScript
- Visual Studio Code Extension API
- TypeScript Compiler API
- Node.js
- Mocha
